# 技术构想：生成 — 校验 — 修正

> 草案，不是实施计划。**验证未通过前不落地代码**，本文只固定两件事：分层边界，和不能妥协的准确性要求。

## 1. 分层

```
用户意图（自然语言 / 模板选择）
        │
        ▼
① 意图解析层：限定学科 / 学段 / 实验类型 / 输出形态
        │      （宁可让用户少选，也不让自由 prompt 直出）
        ▼
② 生成层：结构化中间表示（实验 IR），而不是直接生成 HTML
        │      IR 包含：器材、步骤、参数与单位、现象预期、结论、易错点
        ▼
③ 校验层（核心壁垒）
        │  ├─ 规则校验：量纲/单位、参数取值范围、化学方程式配平、步骤因果顺序
        │  ├─ 知识图校验：概念关系、前置知识、常见迷思（misconception）命中
        │  └─ 一致性校验：结论能否由现象推出，图表与参数是否自洽
        ▼
④ 修正层：把校验失败项回灌给模型重生成（最多 N 轮），仍失败则降级为「待人工复核」
        │
        ▼
⑤ 渲染层：IR → 可交互迷你应用（拖拽/模拟），并输出「知识点—操作—结论」对照表
```

关键取舍：

- **中间表示先行**：结构化 IR 让校验可自动化、可回归测试；直接生成页面等于放弃校验。
- **校验与渲染解耦**：同一份 IR 可渲染成不同形态（课堂演示版 / 学生练习版 / 家长陪读版）。
- **降级而非硬失败**：模型不确定时，明确标注「待核实」，绝不装作确定。

## 2. 校验层的最小可用范围（第一版）

先只做**一个细分组合**，把规则库做深，而不是铺广：

| 候选组合 | 规则可枚举程度 | 说明 |
| --- | --- | --- |
| 初中化学·误差分析型实验 | 高 | 配平、浓度/体积计算、误差来源可列清单 |
| 初中物理·杠杆与摩擦力 | 高 | 单位、公式代入、量级检查可机械校验 |
| 高中生物·显微观察类 | 中 | 操作顺序与观察现象为主，依赖图文一致性 |
| 小学科学·家庭低成本材料 | 中低 | 安全性规则权重高（材料/明火/化学品） |

**安全规则是所有组合的公共前置**：涉及明火、强酸强碱、动物活体、锋利器具的方案必须命中安全模板，缺项直接拒绝生成。

## 3. 测试策略（准确性优先）

- 规则单测：每个物理/化学规则一组正反例，坏例必须被拦下（宁误杀，不漏放）。
- 回归集：把每次线上发现的问题纳入固定用例，防止回退。
- 人工抽检：每批生成内容人工复核比例不低于 20%，记录「流畅但错误」的类型分布。
- 提示词与模型版本变更必须跑全量回归。

## 4. 不合规/不采纳的做法

- 不把裸模型输出直接呈现给未成年人。
- 不做「一键生成整节课」这类无法逐条校验的输出。
- 不在校验层用另一个模型「自己审自己」作为唯一兜底（需要确定性规则做第一道闸）。
- 不采集学生姓名、头像、语音等非必要信息。

## 5. 待定

- IR 的字段定义与版本兼容策略（需与验证阶段的 3–5 份样本对齐后再定）。
- 规则库的存储形态（YAML 声明式 vs 代码内置）。
- 渲染层用现成交互库还是纯静态 SVG/Canvas（先看样本复杂度）。
