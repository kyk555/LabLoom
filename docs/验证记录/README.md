# 验证记录

访谈与使用测试的原始留档。规矩见 `.clinerules/02-验证与测试纪律.md` 第一节。

## 怎么记

- 文件名：`<日期>-<轮次>-<对象类型>.md`，例如 `2026-10-24-R1-教师.md`
- 对象编号：教师 `T1/T2/…`，家长 `P1/P2/…`；**不写真实姓名、学校、联系方式**
- 原话优先：能引就引，转述要标明「转述」
- 每份记录末尾必须有「这轮之后我认为什么变了 / 什么没变」

## 单条记录模板

```markdown
# 2026-10-24 · R1 · 教师

- 样本版本：样例/初中物理/杠杆-01.html（2026-10-24 版）
- 对象：T1（初中物理教师，教龄 8 年）——只说可公开的画像，不写学校
- 使用环境：手机 / 电脑；15 分钟自由使用，我在旁边不引导

## 观察（做了什么，卡在哪）

| 时间 | 动作 | 卡点 / 反应（原话） |
|---|---|---|
| 0–2 min | 打开链接，先看结论 | “结论写在最前面挺好，但我想知道力臂怎么画” |
| 2–5 min | 拖动钩码 | 卡在“拖不动”，试了 3 次 |

## 访谈原话（只记说的，不加解读）

> “这个我上课能直接用，但我得先确认数据对不对。”
> “你会不会给我一个 PDF？我要发给学生。”

## 三个关键问题的回答

1. 还会再用吗？（会 / 不会 / 看情况）→ 理由原话
2. 愿意付钱吗？付多少？（0 / ≤10 / 10–30 / >30 元/月）→ 理由原话
3. 最不能接受的是什么？→ 原话

## 转述与判断（与上面原话分开写）

- 我的判断：……
- 与这轮假设的关系：支持 H1 / 反驳 H1 / 无法判断

## 这轮之后

- 变了什么：……
- 没变什么：……
- 下一步动作（对应 issue 编号）：……
```

## 原始素材

录音、录屏、截图放 `原始素材/`（已在 `.gitignore` 与 `.clineignore` 中屏蔽）：
涉及个人信息，**不入库、不进 AI 上下文**；需要长期保留就单独加密存档。

## 汇总

每轮结束写一份 `汇总-R<n>.md`：样本 → 对象 → 三条假设的通过情况 → 决策门结论（继续 / 收窄 / 放弃）。
