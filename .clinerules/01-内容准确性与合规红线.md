# 内容准确性与合规红线

> 本项目的产品价值全部押在「内容对、不出事」上。以下每条都是 🔴 阻塞级：违反即不得交付，不接受「先上线再说」。

## 一、错误分级（决定处理方式）

| 级别 | 定义 | 例子 | 处理 |
|---|---|---|---|
| 🔴 致命 | 结论错或会引发人身风险 | 结论与现象矛盾；用明火加热密闭容器；把强酸当弱酸 | **不发**，登记 issue，整批回查 |
| 🟠 严重 | 参数 / 单位 / 因果错，但不出危险 | 力矩方向画反、化学方程式未配平、生物过程因果倒置、单位 m 与 cm 混用 | 修好重出，同一模板全量复查 |
| 🟡 轻微 | 表述、措辞、排版 | 现象描述不够具体、术语不统一 | 可先发，进待修清单 |

**「流畅但错误」是本项目的头号敌人**：语言越自然，越容易被当成对的。校验不通过时，标注「待核实」，不许装作确定。

## 二、每份内容必须齐备的字段

缺任何一项都视为未完成：

1. 适用学段与学科、对应课标条目（有就写，没有就写「待补」）
2. 器材清单（含规格 / 替代材料）
3. 操作步骤（可照做，含前置条件）
4. **参数与单位**（数值 + 单位 + 合理范围）
5. 预期现象（可观察、可验证，不是「会发生变化」这种空话）
6. 结论（必须能由现象推出）
7. 常见错误 / 易错点、学生迷思
8. 安全提示（无风险也要写「无需特殊防护」）
9. **依据来源**（教材页码、课标条款、权威资料链接 + 抓取时间）

## 三、学科专项

- **化学**：方程式必须配平（元素守恒逐条核）；反应条件、现象、产物一致；浓度 / 体积计算带量纲；不写「大概会反应」。
- **物理**：量纲与量级先算一遍；公式代入过程可复现；示意图方向（力、电流、光路）与文字一致。
- **生物**：过程顺序（如减数分裂、光合作用）不许颠倒；显微观察的放大倍数与可见结构对应；不把假说写成结论。
- **小学科学**：优先家庭可得的低成本材料；任何涉及明火 / 刀具 / 化学品的方案**必须**给成人陪同提示。

## 四、安全模板（缺项直接拒绝生成）

涉及以下任一情形，必须命中安全模板，否则不出内容：

- 明火 / 高温（酒精灯、加热、燃烧）
- 强酸强碱 / 有毒有害物质 / 不明粉末
- 活体动物、人体样本、血液
- 锋利器具、玻璃器皿、高压 / 真空
- 用电、强磁、激光

**条款依据（2026-10-20 取原文）**：教育部《关于加强和改进中小学实验教学的意见》（教基〔2019〕16 号）第 8 条要求落实实验室安全管理制度、制定实验教学安全预案、定期开展安全风险排查；
《中小学实验室规程》（教基二〔2009〕11 号附件）第八条规定场所安全条件，第十五条要求「科学制定实验操作程序，要有处理突发情况的各项措施，确保教师和学生的人身安全」，第十八条规定化学药品与易燃、易爆、剧毒药品的存放与领用。
**但规程第二十三条把操作级细则交给地方自定**——所以单项实验的安全要求必须查属地细则，不能只凭国家文件放行。
同文第 2 条另有明确指引：「对于……有危险性、破坏性和对环境有危害的实验，可用增强现实、虚拟现实等技术手段呈现」——这是本项目「屏幕演示优先、实物操作谨慎」的政策出处。

## 五、未成年人合规（前置约束，不是事后补救）

- **不设自由 prompt 直出**：任何面向未成年人的内容都要过校验层与审核，不允许用户输入任意文本后直接渲染。
- **数据最小化**：不采集学生姓名、头像、语音、位置；访谈记录去标识化（用「T1 / P1」编号）。
- **输入过滤 + 输出审核**：发现疑似有害内容（暴力、自伤、诱导性内容、邪典风格）→ 立即停止使用该样本，登记 issue，保留原始记录。
- **不推送外部链接**给未成年人；引用材料由成人侧查看。
- **不承诺效果**：不写「提分」「包会」「替代老师」这类表述；定位是辅助工具。

**条款依据（2026-10-20 取原文，报告 E31 / E32）**：

| 本规则 | 条款 |
|---|---|
| 不承诺效果 | 《广告法》第二十四条：教育、培训广告不得含有「对升学、通过考试、获得学位学历或者合格证书，或者对教育、培训的效果作出明示或者暗示的保证性承诺」 |
| 不推广告、不插游戏 | 《未成年人保护法》第七十四条第二款：以未成年人为服务对象的在线教育网络产品和服务，不得插入网络游戏链接，不得推送广告等与教学无关的信息 |
| 数据最小化 | 《未成年人保护法》第七十二条：处理不满十四周岁未成年人个人信息的，应当征得父母或者其他监护人同意；未成年人及监护人可要求更正、删除 |
| 不诱导孩子向家长要东西 | 《广告法》第四十条第二款：针对不满十四周岁未成年人的广告，不得劝诱其要求家长购买，不得含可能引发其模仿不安全行为的内容 |
| 不借学校渠道做广告 | 《广告法》第三十九条：不得在中小学校、幼儿园内开展广告活动，不得利用教材、教辅、练习册、文具、教具、校服、校车等发布或变相发布广告（公益广告除外） |
| 要有投诉渠道 | 《未成年人保护法》第七十八条：应建立便捷、合理、有效的投诉和举报渠道 |

## 六、引用外部材料时

- 留痕三件套：来源 URL + 抓取时间（UTC 与北京）+ 正文 sha256。
- 抓取要伪装真实浏览器（完整请求头 + TLS 指纹），具体做法见全局规则；对方明确拒绝（403/412/429、验证页）就**当天不再碰**这家。
- 二手转述不算依据：要么拿到一手页面，要么写「未能核实」。
