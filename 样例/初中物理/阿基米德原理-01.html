阿基米德原理：浸入比例、排开液体的重力与浮力

这里要较真：页面上 F浮 与 G排 永远相等，是因为两者由同一个式子 ρ液 g V排 算出， 不是测量结果，不能当作实验证据。原理要靠真实实验验证：弹簧测力计测出 F浮，量筒测出 V排，两条路各自算一遍再比。

2　预期现象（可观察、可复述）

  1. 浸入比例从 0 拖到 100 %：F浮 一直变大，且与「浸入比例」成正比（0 % 时为 0，100 % 时为最大值）。
  2. 浸入比例到 100 % 后，再拖动「下沉深度」：F浮 一点不变，读数停在同一个数上。
  3. 把液体从水换成盐水（1.1 g/cm³）：同样体积、同样浸入比例下 F浮 变大 10 %；换成酒精（0.8）则变小 20 %。
  4. 把 g 从 10 换成 9.8：所有浮力读数 按 0.98 倍缩小，但不影响「随 V排 成正比」这个规律。

3　结论（必须能由上面的现象推出来）

F浮 = ρ液 · g · V排（阿基米德原理）

  • 由现象 1 与 2：浮力只由「排开液体的体积」决定，与物体浸得多深无关；
  • 由现象 3：液体越密，同样的 V排 产生越大的浮力；
  • 因此浮力 = 排开液体的重力，写作 F浮 = G排。

注意结论的边界：F浮 与物体本身的重力无关。物体上浮、下沉、悬浮取决于 F浮 与 G物 的大小关系， 那是另一条判断（浮沉条件），不能从本页读数直接得出。

5　真实实验怎么做（本页只是演示，不能替代动手）

器材规格 / 替代
弹簧测力计0—5 N，分度值 0.1 N；无合适量程则换 0—2 N
溢水杯可用剪口塑料瓶 + 弯吸管代替，接口用胶密封
小桶 / 量筒量筒 100 mL，分度值 1 mL
被测物石块或金属块，用细线系牢
  1. 用测力计测出石块重力 G（读数前先校零）。
  2. 溢水杯装水至恰好不溢出，把小桶放在溢水口下方。
  3. 石块缓缓浸没，等水面不再溢出后读测力计示数 F示，得 F浮 = G − F示。
  4. 用量筒量出小桶中水的体积，即 V排；算 G排 = ρ水 g V排（ρ水 取 1.0×10³ kg/m³）。
  5. 比较 F浮 与 G排：两者在误差范围内相等，才算完成验证。

为什么必须动手：本页的 F浮 与 G排 是同一个公式算出来的，相等是设计使然；只有「测力计一路、量筒一路」才算两条独立证据。

6　常见错误与学生迷思

#错误说法错在哪应该怎么说
1「V排 就是物体的体积」只有浸没时两者才相等V排 = V × 浸入比例
2「ρ=1.0、V=50，所以 F=1.0×10×50=500 N」g/cm³ 与 cm³ 直接相乘，差了 1000 倍1.0 g/cm³ → 1000 kg/m³；50 cm³ → 5×10⁻⁵ m³；F=0.500 N
3「物体沉得越深，浮力越大」浸没后 V排 不再增加F浮 只由 ρ液、V排 决定，与深度无关
4「浮力等于物体的重力」把原理与浮沉条件混成一条F浮 = G排；上浮/下沉看 F浮 与 G物 的关系
5「排开液体的体积 = 杯里液体的总量」概念不同：只看物体挤开的那一部分V排 是被物体占去的那块空间

学生迷思（需要当面纠正，不是背下来就行）

  • 「重的物体浮力大」——错。砖头比木块重，浸没时若体积更小，浮力反而更小。
  • 「沉到底就没有浮力了」——错。沉底时仍有浮力，只是 F浮 < G物，所以还要受容器底的支持力。
  • 「在盐水里浮力大是因为盐水更重」——表述不准。是密度更大，在同样 V排 下产生更大的 F浮。
