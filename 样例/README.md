# 样例 · 验证阶段的手工样本

**定位**：这里是「手工产出、逐条核过」的实验交互内容，是验证阶段的产物，**不是产品代码**。
每一份都是单文件 HTML，双击能开、手机能看、不依赖外网。

**当前状态：2 份草稿（v0.1），第 9 项字段「依据来源」均未完成，一律不得外发。**

## 一、清单

| 文件 | 学段 · 学科 | 形态 | 状态 | 依据 |
|---|---|---|---|---|
| `初中物理/阿基米德原理-01.html` | 八年级下 · 物理 | 屏幕演示 + 真实实验步骤 | v0.1 草稿 | 公式已验算；课标 / 教材页码**待核实** |
| `候选-理解型演示/圆面积割补-01.html` | 六年级 · 数学 | 屏幕演示（可拖动、可复算） | v0.1 草稿 | 公式已验算；课标 / 教材页码**待核实** |

> 第二份**不在本项目学科范围内**（项目只做小学科学、初中理化生、高中理化生）。
> 它放在「候选-理解型演示」目录里，用途只有一个：检验 R0 讨论提出的「抽象概念理解型演示」这一候选方向能不能做。
> 它**不代表**项目要接数学内容——这一点也写进了页面本身。

## 二、为什么两份都还不能外发

项目规则要求每份内容齐备 9 项字段，缺任何一项视为未完成。两份样本的第 9 项（依据来源）现状：

| 项 | 物理样本 | 数学样本 |
|---|---|---|
| 公式与数值 | ✅ 逐条验算（含量纲自查） | ✅ 逐条验算 |
| 课标条目 | ⚠️ 未取到《义务教育物理课程标准（2022 年版）》原文 | ⚠️ 未取到《义务教育数学课程标准（2022 年版）》原文 |
| 教材页码 | ⚠️ 未核到版本 / 印次 / 页码 | ⚠️ 未核到版本 / 印次 / 页码 |

**没有原文就不写条款号与页码**——编一个页码比不写更糟：教师一查就发现，之后整份内容都不再可信。
所以两份页面顶部都有醒目的「依据待核实 · 不得外发」条，页面底部也写明了这是草稿。

## 三、这两份样本刻意做到的三件事

1. **结论必须能由现象推出，且数字由参数现算**：改滑块，读数跟着变；不是把答案写死在文字里。
2. **不制造假证据**：
   - 物理页明说 `F浮` 与 `G排` 相等是**同一公式算出来的**，属于设计使然，不能当实验证据；真验证要靠「测力计一路 + 量筒一路」。
   - 数学页明说页面上的「拼图面积 ÷ 圆面积」到不了 100 % 是**画法**（扇形被画成三角形）造成的，割补本身严格不改变面积。
3. **写下边界**：物理页写明「浮力与物体重力无关，浮沉条件是另一条判断」；数学页写明「份数无限多只是无限接近，小学阶段说『越接近』」。

## 四、怎么验

```powershell
# 形态与事实的回归测试（10 项，离线，不读网络）
python -B 工具/测试_样本.py

# 想看渲染后的真实数值：双击打开 HTML，或用真浏览器跑一遍
start 样例\初中物理\阿基米德原理-01.html
```

`工具/测试_样本.py` 守的是：单文件无外网依赖、9 节齐全、关键数值串存在、依据未核实必须显式声明、安全提示不得省、无占位符残留。
它**不守**学科正确性——那只能靠人复核（物理第 2、3、6 节，数学第 3、4、6 节）。
