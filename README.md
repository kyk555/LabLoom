# LabLoom

把 K12 实验内容「织」成可校验、可交互的轻量教学物料。

> 私有项目 · 当前阶段：**先验证需求，再写代码**（见 [`docs/01-验证计划.md`](docs/01-验证计划.md)）

---

## 1. 项目由来

K12 实验内容正在从「软需求」变成「硬指标」：

- 实验操作已纳入初中学业水平考试，有条件地区在探索高中理化生实验操作考试；
- 学生的实验操作与探究实践表现，被要求纳入综合素质评价档案；
- 2026 年多地进入全面落地阶段：科学课时增加、实践素养进综评、实验进中考三条线同步推进。

也就是说，围绕「实验」的内容供给背后，有一个由考试与评价制度撑起来的刚性底盘。
完整的背景拆解见 [`docs/00-背景与可行性分析.md`](docs/00-背景与可行性分析.md)。

## 2. 相信什么 / 不相信什么

| 相信 | 不相信 |
| --- | --- |
| 教师对「快速生成演示实验、交互课件」的需求高频且明确 | 「家长自己动手生成实验内容」是强需求 |
| Vibe Coding 已把「做出来」的门槛降到个人可及 | 「能生成」本身就是壁垒 |
| 细分组合（学科 × 学段 × 实验类型）里仍有大厂不愿深耕的缝隙 | 正面刚通用实验生成平台能赢 |

核心判断：**这个赛道的壁垒不在生成能力，而在教育场景的准确性、合规安全与用户信任。**
竞品（腾讯「懂了鸭」、飞象老师 3.0）已以高度相似的形态入场，窗口正在收窄。

## 3. 当前收敛的方向

不做「面向家长的 K12 实验内容生成平台」，优先从下面三条里选一条推进：

1. **实验内容「校验 + 生成」工具**：先服务教师 / 教研员，解决「AI 生成的实验内容不可信」这个真实痛点。
2. **不碰生成，碰组织**：把已有优质实验视频、仿真、习题，重组成可拖拽、可操作的迷你交互应用。
3. **B 端能力输出**：把生成能力嵌进教师工作流或机构场景，用使用数据验证生成质量与留存。

选哪一条，由验证结果决定，不靠拍脑袋。

### 3.1 调研结论（2026-10-20）

完整取证与推理见 [`报告/2026-10-20-K12实验内容工具-可行性调研与定位建议.html`](报告/2026-10-20-K12实验内容工具-可行性调研与定位建议.html)（26 条证据含 17 条一手公文、4 张图、可离线打开）。

| 结论 | 一句话 |
| --- | --- |
| 原设想 | **不做**「家长自助生成器」：需求错位 + 与腾讯「懂了鸭」正面重合 + 兜底成本随内容量线性增长 |
| 推荐楔子 | 中考实验操作「评分点对齐」微练习：先 1 个地市（铜陵）、3 个实验 |
| 渠道 | 教师端「章节实验改造」；B 端付费有证据（讯飞批阅机续购率 >90%） |
| 终局 | 校验层白标（卖铲子），前提是先攒出错误样本库 |
| 验证 | 4 周、5 个假设；H3（内容正确性）是唯一一票否决项 |
| 范围外赛道 | 象棋 / 历史 / 地理**都不做**：历史地理属学科类（禁区），象棋属非学科但换不到升学（无护城河）。要扩就**换场景不换学科** |
| 学校「没教」的领域 | 财商 / 心理 / 劳动 / 职业 / 性教育 / 学习法**都不能当第二曲线**：六个领域全无计分，且五个课标里已有（财商在道德与法治 4、8 年级与高中数学）。能卖的不是「补缺失」，是替学校把课时填满、把过程留痕（B 端）。财商内容另有硬禁区：不得出现收益排行、产品名、「保本 / 带你买」 |
| To C（直接卖家长） | 八筛：**可试 2**「实验操作单点考前卡」「场馆亲子任务卡」（都不需要许可证）；**形态受限 3**「家庭实验包」「家长端 AI 清单」「理解型单点演示」（最后一项目前只有内部讨论、无用户证据，不进 H1 报价访谈）；**别碰 3** 拍照搜题、卖学科课时包、AI 心理测评。铁律四条：不卖课时、不承诺结果、不给未成年人做测评、不碰别人的形象（影视/动画美术形象受著作权保护） |

## 5. 合规红线（设计前置约束，不是事后补救）

- **生成式 AI 服务义务**：面向未成年人提供服务，需建立安全管理制度与技术措施，不得推送可能影响身心健康的信息。
- **不得暗示「替代」**：定位是辅助工具，不替代教师的专业裁量与家长的判断。
- **内容安全**：输入过滤 + 输出审核必须内建，禁止自由 prompt 直出（涉未成年人不良内容、毒动画、邪典是整治重点）。
- **数据最小化**：不留存未成年人身份信息与影像，默认不训练、不转售。
